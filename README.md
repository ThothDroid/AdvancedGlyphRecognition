# AdvancedGlyphRecognition
Advanced set of data and tools for next level Hieroglyph recognition.

> [!IMPORTANT]
> The work on this repository is still in progress

# Goals of this project

When you look around the web you can see a lot of amateur projects aiming to create AI models which can successfully recognize Egyptian hieroglyphs. In each project, the ai model should recognize the gardener code of the hieroglyphs present in the picture. Although a lot of people tried to implement this, I've never found an open source model which can be used successfully in real-world applications.

In my opinion, such a model should not only be able to recognize one hieroglyph presented in a picture, but should also be able to recognize all hieroglyphs presented in a larger picture. The next step would be to recognize the order and layout of the hieroglyphs to generate a full MdC representation of the text given in the picture.

Such a model would be a powerful tool and the beginning of implementing other powerful tools which can be used by Egyptologists. For example, a hieroglyph translator combined with this AI model would be able to generate a translation of a hieroglyphic artifact given in a picture.
